    Beginner Tutorial — مبتدی ٹیوٹوریل

    Level: Beginner — مبتدی
    Estimated Time: ~4 hours total

    Welcome to the beginner section. These 15 chapters take you from zero to writing real programs in Urdu PL.

    اردو: یہ 15 سبق آپ کو بالکل شروع سے لے کر حقیقی پروگرام لکھنے تک پہنچائیں گے۔

    Chapters — ابواب

    # Topic Urdu Time
    01 Welcome & What is Urdu PL? خوش آمدید ~10 min
    02 Installation تنصیب ~15 min
    03 Hello World ہیلو ورلڈ ~10 min
    04 Variables & Constants متغیرات ~15 min
    05 Data Types ڈیٹا کی اقسام ~15 min
    06 Input & Output ان پٹ / آؤٹ پٹ ~15 min
    07 Strings متن ~20 min
    08 Arithmetic Operators ریاضی آپریٹرز ~15 min
    09 Comparison & Logical Operators موازنہ آپریٹرز ~15 min
    10 If / Else اگر / ورنہ ~20 min
    11 Switch / Case منتخب / صورت ~15 min
    12 While Loop جبکہ لوپ ~20 min
    13 For Loop کے_لیے لوپ ~20 min
    14 Break & Continue ٹوٹنا / جاری ~15 min
    15 Functions فنکشن ~25 min

    What You Will Learn — کیا سیکھیں گے

    By the end of this section you will be able to:

    • Write and run Urdu PL programs
    • Store and use data in variables
    • Read input from the user and display output
    • Work with text, numbers, and booleans
    • Make decisions with اگر/ورنہ
    • Repeat actions with جبکہ and کے_لیے loops
    • Organize code into reusable functions

    اردو: اس سیکشن کے بعد آپ متغیر، ڈیٹا اقسام، ان پٹ/آؤٹ پٹ، شرطی بیانات، لوپ، اور فنکشنز کے ساتھ اصل پروگرام بنا سکیں گے۔
