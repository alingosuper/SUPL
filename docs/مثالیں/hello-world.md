# ہیلو ورلڈ — SUPL مثالیں

یہاں ابتدائی پروگراموں کی مثالیں دی گئی ہیں۔

## 1. سادہ پروگرام

```slk
پندھ_شروع "ہیلو ورلڈ"
    لکھو("السلام علیکم!")
پندھ_مک_گیا
```

## 2. مختلف زبانوں کا تعارف

```slk
پندھ_شروع "مقامی زبانیں"
    لکھو("سرائیکی")
    لکھو("اردو")
    لکھو("پنجابی")
    لکھو("بلوچی")
    لکھو("پشتو")
    لکھو("سندھی")
پندھ_مک_گیا
```

یہ مثال صرف زبانوں کے نام دکھاتی ہے؛ اس سے ہر زبان کے تمام Syntax aliases کی دستیابی ثابت نہیں ہوتی۔

## 3. متغیرات اور حساب

```slk
پندھ_شروع "حساب"
    شے a = 10
    شے b = 20

    لکھو("جمع:", a جمع b)
    لکھو("تفریق:", a منفی b)
    لکھو("ضرب:", a ضرب b)
    لکھو("تقسیم:", b ونڈ a)
پندھ_مک_گیا
```

## 4. شرط

```slk
پندھ_شروع "فیصلہ"
    شے نمبر = 85

    اگر نمبر وڈا 50 {
        لکھو("کامیاب")
    } ورنہ {
        لکھو("ناکام")
    }
پندھ_مک_گیا
```

## 5. فنکشن

```slk
پندھ_شروع "فنکشن"
    کم مربع(x) {
        واپس_ڈیو x ضرب x
    }

    لکھو(مربع(5))
پندھ_مک_گیا
```

## 6. کلاس

```slk
پندھ_شروع "گاڑی"
    کلاس گاڑی {
        تعمیر(ماڈل) {
            یہ.ماڈل = ماڈل
        }

        فنکشن دکھاؤ() {
            لکھو(یہ.ماڈل)
        }
    }

    شے میری_گاڑی = نیا گاڑی("Toyota")
    میری_گاڑی.دکھاؤ()
پندھ_مک_گیا
```

## 7. لائبریری

```slk
پندھ_شروع "ریاضی"
    شامل_کرو "ڳنتری"
    لکھو(ڳنتری.پائی)
پندھ_مک_گیا
```
