# ویب — HTTP Requests

ویب ماڈیول HTTP کے ذریعے ویب سرورز کے ساتھ رابطے کے لیے ہے۔

## شامل کرنا

```slk
شامل_کرو "ویب"
```

## GET درخواست

```slk
شے جواب = ویب.حاصل_کرو("https://api.github.com")
لکھو(جواب)
```

## POST درخواست

```slk
شے جواب = ویب.بھیجو(
    "https://httpbin.org/post",
    {"نام": "علی"}
)

لکھو(جواب)
```

## JSON حاصل کرنا

```slk
شے ڈیٹا = ویب.json_حاصل_کرو(
    "https://api.github.com/users/octocat"
)

لکھو(ڈیٹا)
```

## حفاظتی ہدایات

- صرف قابلِ اعتماد URLs استعمال کریں۔
- حساس معلومات غیر محفوظ HTTP درخواستوں میں نہ بھیجیں۔
- API keys کو پروگرام میں مستقل طور پر محفوظ نہ کریں۔
- نیٹ ورک کی خرابیوں کے لیے Error Handling رکھیں۔
- HTTPS کو ترجیح دیں۔

## آف لائن استعمال

ویب ماڈیول کو استعمال کرنے کے لیے نیٹ ورک درکار ہو سکتا ہے۔ SUPL کے بنیادی پروگرام اس ماڈیول کے بغیر بھی چل سکتے ہیں۔

نوٹ: اصل HTTP Method names اور ان کے Return Types implementation سے تصدیق طلب ہیں۔
