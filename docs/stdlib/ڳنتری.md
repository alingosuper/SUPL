# ڳنتری — ریاضیاتی لائبریری

ڳنتری ماڈیول ریاضیاتی عملیات کے لیے ہے۔

## شامل کرنا

```slk
شامل_کرو "ڳنتری"
```

## بنیادی عملیات

```slk
لکھو(ڳنتری.مطلق(-42))
لکھو(ڳنتری.جذر(16))
لکھو(ڳنتری.طاقت(2, 10))
لکھو(ڳنتری.گول(3.14, 1))
```

## زیادہ اور کم

```slk
لکھو(ڳنتری.زیادہ(5, 3))
لکھو(ڳنتری.کم(5, 3))
```

## مستقل اقدار

```slk
لکھو(ڳنتری.پائی)
لکھو(ڳنتری.ای)
```

## مثلثی عملیات

```slk
لکھو(ڳنتری.سائن(1.57))
لکھو(ڳنتری.کوسائن(0))
لکھو(ڳنتری.ٹینجنٹ(0))
```

## بے ترتیب اعداد

```slk
لکھو(ڳنتری.بے_ترتیب_عدد(1, 100))
```

## فہرست میں سے انتخاب

```slk
شے فہرست = [1, 2, 3, 4, 5]

ڳنتری.بے_ترتیب(فہرست)
لکھو(ڳنتری.چنو(فہرست))
```

## احتیاط

- جذر کے لیے درست عددی حد کا خیال رکھیں۔
- بے ترتیب اعداد کو حفاظتی مقاصد کے لیے استعمال نہ کریں جب تک محفوظ Random Generator کی تصدیق نہ ہو۔
- زاویوں کی اکائی (Radians یا Degrees) چیک کریں۔

نوٹ: ان تمام فنکشنز کی اصل دستیابی stdlib implementation سے مشروط ہے۔
