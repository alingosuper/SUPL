# فائلاں — فائلوں کا انتظام

فائلاں ماڈیول کا مقصد فائلوں کو پڑھنا، لکھنا اور ان کا انتظام کرنا ہے۔

## شامل کرنا

```slk
شامل_کرو "فائلاں"
```

## فائل پڑھنا

```slk
شے مواد = فائلاں.پڑھو("test.txt")
لکھو(مواد)
```

## فائل لکھنا

```slk
فائلاں.لکھو("test.txt", "السلام علیکم")
```

## مواد شامل کرنا

```slk
فائلاں.شامل_کرو("test.txt", "نئی لائن")
```

## فائل کی موجودگی

```slk
اگر فائلاں.موجود_ہے("test.txt") {
    لکھو("فائل موجود ہے")
}
```

## فائلوں کی فہرست

```slk
شے فائلیں = فائلاں.فہرست(".")
لکھو(فائلیں)
```

## احتیاط

- فائل لکھنے سے پہلے راستہ چیک کریں۔
- اہم فائلوں کا بیک اپ رکھیں۔
- صرف قابلِ اعتماد راستوں پر کام کریں۔
- فائل آپریشنز میں اجازت اور Error Handling کا خیال رکھیں۔

نوٹ: تمام Method names کی دستیابی اصل stdlib implementation سے مشروط ہے۔
