# ویلہ — تاریخ اور وقت

ویلہ ماڈیول تاریخ اور وقت سے متعلق عملیات کے لیے ہے۔

## شامل کرنا

```slk
شامل_کرو "ویلہ"
```

## موجودہ وقت

```slk
لکھو(ویلہ.اب())
```

## آج کی تاریخ

```slk
لکھو(ویلہ.آج())
```

## تاریخ کے حصے

```slk
لکھو(ویلہ.سال())
لکھو(ویلہ.مہینہ())
لکھو(ویلہ.دن())
```

## تاریخ کی فارمیٹنگ

```slk
لکھو(ویلہ.فارمیٹ("%d/%m/%Y"))
```

## انتظار

```slk
ویلہ.سو_جاؤ(2)
```

## دو تاریخوں کا فرق

```slk
شے دن = ویلہ.فرق_دن(
    "2026-01-01",
    "2026-12-31"
)

لکھو(دن)
```

## استعمالات

- حاضری کا نظام
- دفتری ریکارڈ
- وقت کے حسابات
- تاریخ کی ترتیب
- یاد دہانیوں کے نظام

نوٹ: Method names، Date format اور Timezone کا رویہ اصل implementation کے مطابق ہوگا۔
