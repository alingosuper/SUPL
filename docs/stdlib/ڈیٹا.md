# ڈیٹا — JSON اور CSV

ڈیٹا ماڈیول کا مقصد ساختہ ڈیٹا کو پڑھنا اور محفوظ کرنا ہے۔

## شامل کرنا

```slk
شامل_کرو "ڈیٹا"
```

## JSON ڈیٹا

```slk
شے ریکارڈ = {
    "نام": "علی",
    "عمر": 25
}
```

## JSON میں تبدیل کرنا

```slk
شے متن = ڈیٹا.json_میں(ریکارڈ)
لکھو(متن)
```

## JSON سے واپس تبدیل کرنا

```slk
شے واپس = ڈیٹا.json_سے(متن)
لکھو(واپس)
```

## CSV پڑھنا

```slk
شے قطاریں = ڈیٹا.csv_پڑھو("data.csv")
لکھو(قطاریں)
```

## CSV لکھنا

```slk
شے ریکارڈ = [
    {"نام": "علی", "عمر": 25}
]

ڈیٹا.csv_لکھو("out.csv", ریکارڈ)
```

## استعمالات

- طلبہ کا ریکارڈ
- دفتری معلومات
- مالیاتی اندراجات
- ڈیٹا کی منتقلی
- JSON APIs

## احتیاط

غیر معتبر JSON یا CSV ڈیٹا کو استعمال کرنے سے پہلے Validate کریں۔

نوٹ: تمام API ناموں اور ڈیٹا اقسام کی دستیابی اصل ماڈیول سے مشروط ہے۔
