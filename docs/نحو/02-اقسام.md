# 02 — ڈیٹا اقسام

ڈیٹا اقسام بتاتی ہیں کہ متغیر میں کس نوعیت کی قدر محفوظ ہے۔

## عدد

```slk
شے عمر = 25
شے نمبر = 100
```

## اعشاری عدد

```slk
شے قیمت = 99.50
شے PI = 3.14159
```

## متن

```slk
شے نام = "علی"
شے پیغام = "السلام علیکم"
```

## Boolean

```slk
شے کامیاب = سچ
شے ناکام = کوڑ
```

## خالی قدر

```slk
شے نتیجہ = خالی
```

## فہرست

```slk
شے نمبر = [10, 20, 30]
```

## لغت

```slk
شے طالب_علم = {
    "نام": "علی",
    "عمر": 20
}
```

لغت اور فہرست کی مکمل سہولت Parser اور Runtime کی دستیاب خصوصیات کے مطابق ہوگی۔

## مثال

```slk
پندھ_شروع "ڈیٹا اقسام"
    شے نام = "علی"
    شے عمر = 20
    شے نمبر = 85.5
    شے کامیاب = سچ

    لکھو(نام)
    لکھو(عمر)
    لکھو(نمبر)
    لکھو(کامیاب)
پندھ_مک_گیا
```
