# 01 — متغیرات

متغیر کسی قدر کو محفوظ کرنے کے لیے استعمال ہوتا ہے۔

## اعلان

```slk
شے نام = "علی"
شے عمر = 25
شے شہر = "ملتان"
```

## مختلف زبانوں کے الفاظ

```slk
شے نام = "علی"
متغیر عمر = 25
چیز شہر = "کوئٹہ"
توکی نوم = "احمد"
شئي نالو = "کراچی"
```

ان متبادل الفاظ کی دستیابی متعلقہ Lexer لغت پر منحصر ہے۔

## قدر تبدیل کرنا

```slk
شے x = 10

x = 20
x = x جمع 5

لکھو(x)
```

متوقع نتیجہ:

```text
25
```

## مستقل

```slk
پکی PI = 3.14
مستقل MAX = 100
```

## متغیر کے نام

- نام واضح رکھیں۔
- نام میں غیر ضروری خالی جگہ استعمال نہ کریں۔
- زبان کے مخصوص Reserved Keywords کو متغیر کا نام نہ بنائیں۔
- بڑے اور چھوٹے حروف کا رویہ Lexer کے قواعد کے مطابق ہوگا۔

## مکمل مثال

```slk
پندھ_شروع "طالب علم"
    شے نام = "احمد"
    شے نمبر = 85

    لکھو("طالب علم:", نام)
    لکھو("نمبر:", نمبر)
پندھ_مک_گیا
```
