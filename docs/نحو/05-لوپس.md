# 05 — لوپس

لوپ کسی کام کو بار بار انجام دینے کے لیے استعمال ہوتا ہے۔

## جبکہ

```slk
شے x = 0

جدوں_تئیں x نکا 5 {
    لکھو(x)
    x = x جمع 1
}
```

## برائے

```slk
برائے i میں 0 تک 5 {
    لکھو(i)
}
```

اس مثال میں حد اور آخری عدد کا رویہ زبان کے range implementation کے مطابق ہوگا۔

## لوپ روکنا

```slk
شے x = 0

جدوں_تئیں سچ {
    اگر x برابر 5 {
        روک_ڈیو
    }

    لکھو(x)
    x = x جمع 1
}
```

## اگلی تکرار

```slk
برائے i میں 0 تک 10 {
    اگر i برابر 3 {
        اگے_ٹرو
    }

    لکھو(i)
}
```

## احتیاط

- لوپ کی شرط تبدیل کرنا نہ بھولیں۔
- غیر محدود لوپ سے بچیں۔
- BREAK اور CONTINUE کے درست الفاظ Lexer سے تصدیق کریں۔
