# 07 — کلاسز اور آبجیکٹس

Object-Oriented Programming میں کلاس ایک ساخت ہے جس سے آبجیکٹس بنائے جاتے ہیں۔

## بنیادی کلاس

```slk
کلاس شخص {
    تعمیر(نام، عمر) {
        یہ.نام = نام
        یہ.عمر = عمر
    }

    فنکشن دکھاؤ() {
        لکھو("نام:", یہ.نام)
        لکھو("عمر:", یہ.عمر)
    }
}

شے علی = نیا شخص("علی"، 25)
علی.دکھاؤ()
```

## Methods

```slk
کلاس کیلکولیٹر {
    تعمیر() {
        یہ.نتیجہ = 0
    }

    فنکشن جمع(x) {
        یہ.نتیجہ = یہ.نتیجہ جمع x
        واپس_ڈیو یہ
    }

    فنکشن دکھاؤ() {
        لکھو("نتیجہ:", یہ.نتیجہ)
    }
}

شے calc = نیا کیلکولیٹر()
calc.جمع(10).دکھاؤ()
```

## وراثت

وراثت کے لیے متعلقہ Parser اور Runtime میں دستیاب کلاس inheritance کی Syntax استعمال کریں۔ اس کی غیر مصدقہ مثال کو قابلِ عمل کوڈ نہ سمجھیں۔

## اصطلاحات

- Class: کلاس
- Object: آبجیکٹ
- Constructor: تعمیر
- Method: طریقۂ کار
- Property: خاصیت
- Inheritance: وراثت
