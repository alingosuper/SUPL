# 06 — فنکشنز

فنکشن کوڈ کے ایسے حصے ہیں جنہیں ضرورت کے وقت بار بار چلایا جا سکتا ہے۔

## سادہ فنکشن

```slk
کم سلام() {
    لکھو("السلام علیکم")
}

سلام()
```

## پیرامیٹرز

```slk
کم سلام(نام) {
    لکھو("سلام", نام)
}

سلام("علی")
```

## واپسی کی قدر

```slk
کم جمع(الف، ب) {
    واپس_ڈیو الف جمع ب
}

شے نتیجہ = جمع(5، 3)
لکھو(نتیجہ)
```

متوقع نتیجہ:

```text
8
```

## متعدد پیرامیٹرز

```slk
کم ضرب(الف، ب) {
    واپس_ڈیو الف ضرب ب
}

لکھو(ضرب(4، 5))
```

## Recursion

```slk
کم factorial(n) {
    اگر n برابر 1 {
        واپس_ڈیو 1
    }

    واپس_ڈیو n ضرب factorial(n منفی 1)
}

لکھو(factorial(5))
```

متوقع نتیجہ:

```text
120
```

نوٹ: Recursion کی حد Runtime کی صلاحیت پر منحصر ہے۔
