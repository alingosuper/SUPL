# 04 — شرائط

شرائط پروگرام کو کسی مخصوص حالت کے مطابق فیصلہ کرنے دیتی ہیں۔

## اگر

```slk
شے عمر = 20

اگر عمر وڈا 18 {
    لکھو("بالغ")
}
```

## اگر / ورنہ

```slk
شے عمر = 16

اگر عمر وڈا 18 {
    لکھو("بالغ")
} ورنہ {
    لکھو("نابالغ")
}
```

## ورنہ اگر

```slk
شے نمبر = 85

اگر نمبر وڈا 90 {
    لکھو("A")
} ورنہ_اگر نمبر وڈا 80 {
    لکھو("B")
} ورنہ {
    لکھو("مزید محنت کریں")
}
```

## متعدد شرائط

```slk
اگر عمر وڈا 18 تے نمبر وڈا 50 {
    لکھو("شرط پوری")
}
```

## منتخب / صورت

```slk
منتخب x {
    صورت 1 {
        لکھو("ایک")
    }

    صورت 2 {
        لکھو("دو")
    }

    ڈیفالٹ {
        لکھو("نامعلوم")
    }
}
```

نوٹ: Switch کی Syntax اور الفاظ Parser میں دستیاب ہونے کی صورت میں استعمال کریں۔
