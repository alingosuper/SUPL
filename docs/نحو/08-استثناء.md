# 08 — استثناء اور خرابیوں کا انتظام

Exception Handling سے پروگرام میں پیدا ہونے والی خرابیوں کو سنبھالا جا سکتا ہے۔

## کوشش / پکڑو

```slk
کوشش {
    شے نتیجہ = 10 ونڈ 0
} پکڑو(غلطی) {
    لکھو("خرابی:", غلطی)
}
```

## کوشش / پکڑو / آخر میں

```slk
کوشش {
    لکھو("کام شروع")
    شے x = 10 ونڈ 0
} پکڑو(غلطی) {
    لکھو("خرابی:", غلطی)
} آخر_میں {
    لکھو("کام مکمل")
}
```

## خرابی پھینکنا

```slk
کم تقسیم(الف، ب) {
    اگر ب برابر 0 {
        پھینکو "صفر سے تقسیم نہیں ہو سکتا"
    }

    واپس_ڈیو الف ونڈ ب
}
```

## مکمل مثال

```slk
پندھ_شروع "استثناء"
    کوشش {
        لکھو("پروگرام چل رہا ہے")
    } پکڑو(غلطی) {
        لکھو("خرابی:", غلطی)
    } آخر_میں {
        لکھو("اختتام")
    }
پندھ_مک_گیا
```

## فوائد

- پروگرام کو غیر متوقع خرابیوں سے محفوظ رکھنا۔
- صارف کو مناسب پیغام دکھانا۔
- ضروری اختتامی کام انجام دینا۔

نوٹ: Exception کی اصل اقسام اور Syntax Runtime کی implementation کے مطابق ہوں گی۔
