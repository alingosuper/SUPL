# SUPL کی تنصیب

## ضروریات

- Python 3
- pip
- Terminal یا Termux
- SUPL کا سورس کوڈ یا دستیاب پیکیج

## طریقہ 1: pip کے ذریعے

```bash
python -m pip install supl-lang
```

تنصیب کی جانچ:

```bash
python -m pip show supl-lang
```

## طریقہ 2: سورس کوڈ سے

```bash
git clone https://github.com/empowerdeveloprs/SUPL.git
cd SUPL
```

Virtual Environment بنائیں:

```bash
python -m venv .venv
```

فعال کریں:

Linux / Termux:

```bash
source .venv/bin/activate
```

Windows:

```powershell
.venv\Scripts\activate
```

Dependencies انسٹال کریں:

```bash
pip install -r requirements.txt
```

اگر پیکیج کی ساخت setup.py استعمال کرتی ہے:

```bash
pip install -e .
```

## پروگرام چلانا

```bash
saraiki hello.slk
```

یا اگر منصوبے میں `supl` کمانڈ رجسٹرڈ ہو:

```bash
supl hello.slk
```

## تنصیب کی تصدیق

```bash
python --version
pip show supl-lang
```

## عام مسائل

### Command not found

Virtual Environment فعال کریں اور پیکیج کی CLI entry point چیک کریں۔

### Module not found

```bash
pip install -e .
```

### Parser Error

- کلیدی الفاظ کی درست املا دیکھیں۔
- بریکٹس اور کوڈ بلاکس بند کریں۔
- اپنے پروگرام کی Syntax چیک کریں۔

### Dependencies کا مسئلہ

```bash
pip install -r requirements.txt
```

نوٹ: CLI کمانڈز کی حتمی دستیابی پیکیج کی اصل configuration پر منحصر ہے۔
