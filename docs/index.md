# SUPL — سُپل پروگرامنگ زبان

> Saraiki + Urdu + Punjabi + Balochi + Pashto + Sindhi
>
> **6 زبانیں، ایک پروگرامنگ زبان**

SUPL ایک کثیر لسانی پروگرامنگ زبان ہے جس کا مقصد مقامی زبانوں میں پروگرامنگ کو آسان بنانا ہے۔

## زبانیں

| زبان | متغیر کی مثال |
|---|---|
| سرائیکی | `شے x = 10` |
| اردو | `متغیر x = 10` |
| پنجابی | `شے x = 10` |
| بلوچی | `چیز x = 10` |
| پشتو | `توکی x = 10` |
| سندھی | `شئي x = 10` |

نوٹ: ہر متبادل لفظ کی دستیابی Lexer کی اصل keyword registry پر منحصر ہے۔

## خصوصیات

- متعدد مقامی زبانوں کے کلیدی الفاظ
- متغیرات اور مستقل اقدار
- بنیادی ڈیٹا اقسام
- ریاضی اور منطقی آپریٹرز
- شرائط اور لوپس
- فنکشنز اور واپسی کی اقدار
- کلاسز اور آبجیکٹس
- Exception Handling
- معیاری لائبریری

## پہلا پروگرام

```slk
پندھ_شروع "میرا پروگرام"
    لکھو("السلام علیکم دنیا!")
پندھ_مک_گیا
```

چلانے کا طریقہ:

```bash
saraiki hello.slk
```
